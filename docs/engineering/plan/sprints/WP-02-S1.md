### What is needed

| Acceptance item | Gap | Approach |
|---|---|---|
| `fixtures/legacy/*`, at least 17, each with the upstream SHA and source references | No files; no model of the canonical behavior; no traces for an application-set `cache-offline: false` or `http`, for 3xx, 404 and `POST` pass-through | A JavaScript legacy model and generator in `tools/legacy-fixtures/` (`gen.mjs --check`, the pattern of `tools/rqp-protocol/gen.mjs`); the profile fixtures are checked byte for byte against the stored traces; missing scenarios are traced in S2 |
| Each server divergence D-01…D-13 has a profile and a fixture (G1, H-110) | No fixtures | One override fixture per profile where the profile differs from `legacy-canonical` (ADR-005) |
| `fixtures/malformed/*` | Missing | Negative request fields, broken marker pages, fuzz seeds; expected: no crash and the normal or full document (S2) |
| The runner tests a server by URL | The checker runs in-process only; a server under test cannot get a page and an application response per case | `server/conformance` (DL-065, DL-066) |
| WP-03 can pass both suites | — | The same runner and control contract for the RQP `P` cases; the target URL stays `https://shop.example.com/catalog` through the `Host` field |
| `fulltest.sh` and CI | — | New steps in the `node` group: unit tests, `gen --check`, trace check, runner over HTTP against the RQP reference, the server demo `rqp.js` and the legacy model (four profiles) |

**Reuse.** The compare helpers and fixture loaders of `tools/rqp-protocol`; the RQP `expected.json` files; the servers that fail on purpose; the model and scenarios of `run_traces.py` (Rivqen code; the marker expression is a wire-grammar item, CR-03); the 13 lab pages; the 93 stored traces; the lab harnesses (they get the control endpoint in S2).

**New.** A raw HTTP client on `node:http` (exact field lines, no automatic decoding); the control client and the harness server; the legacy model and generator; the legacy comparison (repeated fields, data JSON semantic or byte-exact, no body); profile selection; the command line and the report; the malformed suite (S2).
