### Human decisions

| ID | Question | Decision |
|---|---|---|
| H-113 | HTTP stack and dependencies of the reference server. Measured on 2026-10-31 (clean release build, Apple Silicon, toolchain 1.99.0): std only 0 crates, 378 KB stripped; tiny_http 0.12.0 5 crates, 687 KB, no limit on a request line (memory DoS), always adds `Server` and `Date`; hyper 1.12.0 with tokio 1.54.1 22 crates, 880 KB; axum 0.8.9 36 crates, 1.1 MB. hyper and axum lowercase the request field names and group repeated response lines; the original name case is not readable (`HeaderCaseMap` is `pub(crate)`), so `FX-LEG-DETECT-NAME-CASE--PHP` (`Accept-Diff` is not `accept-diff` for PHP, D-01) cannot pass. Every measured crate is MIT, Apache-2.0, BSD-3-Clause, Unicode-3.0 or `Unlicense OR MIT` (`docs/legal/third-party.md`: allowed) | **Own HTTP/1.1 reader on `std` and four crates: `sha1`, `sha2`, `base64`, `serde_json`** (human, 2026-10-31). 17 crates in all; no async runtime; exact request names and exact response field lines |
| H-114 | What the reference server does outside the conformance mode ("serves the conformance lab") | **Conformance mode and a static site mode** (human, 2026-10-31): `--site <dir>` serves the HTML files of a directory as the application response and applies legacy or RQP by configuration; no reverse proxy (a proxy needs an HTTP client and more attack surface; WP-19 can add it). The site mode is in S2 |
| H-115 | Container image | **Multi-stage build, runtime `scratch` with a static musl binary, non-root, no shell; both `FROM` lines pinned by digest in WP-03** (human, 2026-10-31). The builder is the official `rust` image of the pinned toolchain. Tests publish the port on `127.0.0.1` only. In S2 |

| Site mode | Missing | S2: `--site <dir>` (H-114) |
| `fulltest.sh` and CI | No step | `run.mjs --command`; group `rust` builds the binary and runs the runner (RQP, four profiles, malformed); the CI job that installs the toolchain runs it (DL-090) |
| Mandatory properties | — | Linear time (C-16; own reader and SF parser); request field section of at least 8 KiB (CONTRACT §3; limit 64 KiB, then `431`); case body at most 8 MiB (`413`); no panic on input (lints of the candidate, `catch_unwind` per connection as the last guard); a release build answers the application response unchanged on an internal error (`500` only in the conformance mode, CONTRACT §2); logs without field values, bodies or query strings |
