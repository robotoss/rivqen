## 1. Kickoff

Kickoff on 2026-11-08. WP-01 is merged into `main` (7282f8d, #8, 2026-11-08), so the dependency of WP-04 is met. P2 proves what Android and iOS can do with public APIs. Gate G2: "Android and iOS feasibility proven with public APIs; incompatibilities documented publicly (ADRs)" ([gates](/engineering/plan/gates)). WP-09 needs WP-04, and WP-10 and WP-11 need WP-09. The [roadmap](/engineering/plan/roadmap) names the iOS spike as the most likely delay, so S1 starts it.

### Platform facts found at kickoff

<Badge type="tip" text="FACT" /> Checked on 2026-11-08 by a research pass. The lanes check again what they use.

| Fact | Source |
|---|---|
| `shouldInterceptRequest` runs "on a thread other than the UI thread"; a 3xx status in `WebResourceResponse` is "not supported"; the method is called only for the initial resource URL, not for redirect URLs | [WebViewClient](https://developer.android.com/reference/android/webkit/WebViewClient), [WebResourceResponse](https://developer.android.com/reference/android/webkit/WebResourceResponse) |
| androidx.webkit 1.15.0 added `WebResourceResponseCompat#setCookies` and `WebSettingsCompat.setCookiesIncludedInShouldInterceptRequest` (feature `COOKIE_INTERCEPT`); androidx.webkit 1.18.0 is stable, minSdk 24 | [androidx.webkit releases](https://developer.android.com/jetpack/androidx/releases/webkit) |
| WebView is updatable through Google Play from Android 5.0; Chromium no longer supports WebView updates on Android 5–9 | [Lollipop](https://developer.android.com/about/versions/lollipop), [Chromium WebView prerelease](https://chromium.googlesource.com/chromium/src/+/HEAD/android_webview/docs/prerelease.md) |
| Device share (Android Studio data, 2026-10-01): API ≥ 24 99.4 %, ≥ 26 99.0 %, ≥ 28 97.0 %, ≥ 29 93.9 % | [distributions.json](https://dl.google.com/android/studio/metadata/distributions.json) |
| Registering a `WKURLSchemeHandler` for a scheme that WebKit handles (for example `https`) raises `NSInvalidArgumentException`; `loadSimulatedRequest` (both forms) is iOS 15.0+ | [setURLSchemeHandler](https://developer.apple.com/documentation/webkit/wkwebviewconfiguration/seturlschemehandler(_:forurlscheme:)), [loadSimulatedRequest](https://developer.apple.com/documentation/webkit/wkwebview/loadsimulatedrequest(_:response:responsedata:)) |
| Service Workers in `WKWebView` need App-Bound Domains: forum and bug reports only; Apple documentation: NOT FOUND | [WebKit list 2021-10](https://lists.webkit.org/pipermail/webkit-unassigned/2021-October/1005715.html) |
| UniFFI 0.32.2 (MPL-2.0): Kotlin calls Rust through JNA; `bytes` are copied into a `RustBuffer`; zero copy only for `&[u8]` arguments into Rust (0.32.0). Published empty-call cost: Kotlin 2.89 µs, Swift 165 ns (Apple M4 Max) | [UniFFI changelog](https://raw.githubusercontent.com/mozilla/uniffi-rs/main/CHANGELOG.md), [uniffi-bindgen-java benches](https://docs.rs/crate/uniffi-bindgen-java/0.4.1/source/benches/README.md) |
| JNA is LGPL-2.1+ or Apache-2.0; `jni` 0.22.4 is MIT or Apache-2.0; cbindgen 0.29.4 is MPL-2.0 | [JNA](https://github.com/java-native-access/jna), crates.io |
| Foundation `URL` (apps linked on or after iOS 17) parses by RFC 3986 like `URLComponents`, not by WHATWG | [URL init(string:)](https://developer.apple.com/documentation/foundation/url/init(string:)) |

### Rules for every lane

- Clean-room. No upstream code; WP-04 needs no upstream lab.
- Lab root `/Volumes/BackCat/rivqen-p2-lab` (DL-138). Do not use `/Volumes/BackCat/rivqen-lab`.
- Never touch `emulator-5554` or a simulator of the human. Give every `adb` call the lab serial `emulator-5602`. Run one Android emulator at a time.
- Keep at least 20 GB free on the system volume. Put the Rust `target/`, Gradle and DerivedData in the lab root, not in `/tmp`.
- Lanes do not start mutation runs. The architect gives each mutation run a slot. `cargo-mutants -j 1 --timeout 60`, `RUST_TEST_THREADS=4`, `--iterate`. Stryker only detached with `nohup`; then check `git status`.
- No secrets and no personal data in traces or recordings. Cookie values are synthetic. No trust-all TLS, no ATS exception, no private API.
- Platform facts come from the documentation with a source, or are NOT FOUND.
