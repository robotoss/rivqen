## 5. Decisions and follow-ups

- Decisions: DL-153, DL-154, DL-155, DL-156
- For WP-08: `RivqenError` is at least 128 bytes, so `clippy::result_large_err` fires on every function that returns it (`Engine::new` has an `expect` with a reason); box the `Context` in `rivqen-model` before WP-08 adds many such functions. Events and actions get the session envelope (generation, request id; INV-12, core API rule 3). Placeholder payloads keep a `Debug` without data.
- For the human (with the merge request): a new error code `CONFIG_INVALID` instead of `INTERNAL_ERROR` for a configuration outside the safe ranges (DL-155, API).
- Carried from S1: WP-08 items of [S1 §5](/engineering/plan/sprints/WP-05-S1#_5-decisions-and-follow-ups) (URL form in logs, `SafeUrl` host rule, no `Error::source` walk in logs, C27 URL canonicalization)
