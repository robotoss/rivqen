### Decisions of the human for S2

| ID | Question | Decision (2026-11-22) |
|---|---|---|
| H-150 | Q-27: the consent of the server for authenticated caching of an RQP response | **An explicit `Cache-Control: private` or `public`.** A credentialed RQP response is stored only when the app sets `authenticated_cache` and the response has one of the two directives. Legacy mode keeps CL-25 (`cache-offline` is the consent). Not chosen: no `no-store` is enough; a new manifest member |
| H-151 | ADR-011: which entries the driver encrypts | **Every entry**: scoped entries with the key of their partition, `public` entries with the key of `public`. Not chosen: scoped and marked entries only; authenticated partitions only |

### Decisions of the architect

| ID | Topic | Decision |
|---|---|---|
| DL-203 | Storage form | One sealed file for each entry version, SQLite metadata with `synchronous=FULL`, recovery in five steps: [ADR-004](/engineering/architecture/adr/ADR-004-cache-storage) (Proposed) |
| DL-204 | Sealed form and the key port | `RQS1`, random nonce and file id from the key port, associated data with role, schema, partition, key and file id; the row metadata beyond the address is sealed too: [ADR-011](/engineering/architecture/adr/ADR-011-cache-encryption) (Proposed). No random-number dependency |
| DL-205 | Contract changes before the driver | A precondition for the epoch of the request partition; `recover(now)`; a host check with `Refused::InvalidHost` (S1 security review L2, L4; code review finding 5) |

| DL-208 | Host check and request precondition | No embedded IPv4 and no zone in an IPv6 literal (H-80); `request: None` only for maintenance; the rule order of DL-200 with the two new checks |
