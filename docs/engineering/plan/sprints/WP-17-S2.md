## 1. Scope and inputs

Human decisions that S2 implements (sprint record S1, §1): H-1 (manifest inline only), H-2 (full SHA-256, base64url), H-4 (`dict-compression` token reserved), H-7 (client block digests in a request header; all-blocks fallback), H-8 (revisions `t1.`/`r1.`), H-9 (no `page_id`/`sequence` over HTTP), H-10 (hash per operation), H-11 (JSON envelope, string content, no JCS), H-28 (client compares the manifest type by ASCII case-insensitive byte match).

Moved to sprint S3: H-40 (relaxation studies), H-42 (`noscript` content model).
