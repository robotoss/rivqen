# Project status

**Current stage:** Phase P0 (Foundation and evidence) is **closed**: milestone **M1 "init docs"** is delivered and gate **G0** is passed. Phase P1 — Contracts: WP-17 (RQP specification) sprint S1 is closed: the RQP markup rules are normative and four parser candidates agree on all golden markup fixtures. Sprint S2 is closed: negotiation, manifest and patch of `rqp/1` are normative, with JSON Schemas, 174 protocol fixtures (78 server, 96 client) and a server demo that passes them. Sprint S3 is closed: the `noscript` content model (H-71), the manifest after the head start tag (H-72) and `svg`/`math` in blocks (H-73…H-75) are normative and in all four parser candidates; 820 of 882 corpus pages are valid. Sprint S4 is closed: the audit follow-up relaxed the over-tight rules (H-77, H-78: patch-safety checks moved from the markup to the patch content rule; H-79a implied head; H-84; H-85a implied table closure; H-86 JSON-LD), so 91.5 % of the small and 66.5 % of the main block variants of the corpus are valid (S3: 81.8 % and 35.1 %); 813 of 868 corpus pages are valid. Sprint S5 is closed: `template` and `noscript` are allowed in blocks (H-94…H-97, DL-056; main block variants of the corpus 80.2 %), the patch apply step is normative (H-102), and WebView checks on iOS and Android confirm the scripting-disabled parse and the delivery rules (Q-19, Q-20). Sprint S6 is closed: the manifest and the delta carry only what the client cannot compute (H-103, H-104), a delta is bound to its URL, base and a client nonce (H-107…H-109), and field parsing is linear (DL-063); on the demo page RQP now sends 2,357 bytes gzip on a cold visit (legacy 2,232) and 217 on a data change (legacy 316). WP-17 is done and merged into `main` on 2026-10-20 (#3). WP-02 (legacy golden suite and conformance runner) is done and merged into `main` (2026-10-31, #5): 171 legacy fixtures confirmed by 117 upstream traces, 22 malformed cases, and a runner that tests a server by URL, also against the live upstream servers. WP-03 (Rust reference server) sprint [S1](/engineering/plan/sprints/WP-03-S1) is closed: the reference server, written independently of the JavaScript models, passes by URL the RQP suite (112/112), the legacy suite in all four profiles and the malformed suite, and gate **G1** is passed (human, 2026-11-02). WP-03 is done and merged into `main` (2026-11-04, #6): the reference server also runs as a pinned container image with a per-run control token and serves a site directory with legacy or RQP; 29 new RQP cases pin the open inputs of negotiation §4. WP-01 (client part, H-110) sprint [S1](/engineering/plan/sprints/WP-01-S1) is closed: the legacy client is described from code and from client traces (Q-02 answered; client divergences D-20…D-52 with a Rivqen canonical value). Sprint [S2](/engineering/plan/sprints/WP-01-S2) is closed: every legacy client behavior that G3 checks has a client fixture with an expected result from a Rivqen client model, checked against the stored client traces; WP-01 is done and merged into `main` (2026-11-08, #8). Phase P2 is **closed**: WP-04 (platform spikes, gate G2): [S1](/engineering/plan/sprints/WP-04-S1) is closed (2026-11-08): on Android API 37 an early native fetch can be the intercepted main document and its status and CSP reach the page, but the WebView passes a streamed body on in 2048-byte blocks (conditional); on iOS 27.0 `loadSimulatedRequest` and real navigation work, cookies need a sync into `WKHTTPCookieStore`, and streaming an `https` main document is impossible with public API; the FFI benchmark on the Mac host shows UniFFI about 20–40 times slower than a C ABI for 1 MiB (indicative). [S2](/engineering/plan/sprints/WP-04-S2) is closed (2026-11-08): every capability has a verdict on Android API 37 and 29 and on iOS 27.0, 26.5 and 18.5, among them redirects, TLS errors, cookie sync, CSP, Service Worker and history; the native early fetch is limited so that it sends the same SameSite cookies as the web view (H-131, H-132). [S3](/engineering/plan/sprints/WP-04-S3) is closed (2026-11-09): the parity matrices are generated from the capability catalog, 11 screen recordings show the key capabilities, ADR-002 (FFI: UniFFI control plane and a C ABI byte channel) and ADR-003 (iOS: one path per page class, no `https` streaming) are accepted, and gate **G2** is passed (human, H-137). WP-04 is done and merged into `main` (2026-11-09, #9). **Now:** Phase P3 — WP-05 (Rust core workspace, data model, errors, testkit; H-130): sprint [S1](/engineering/plan/sprints/WP-05-S1) is closed (2026-11-11): the core workspace builds in CI on the pinned toolchain, with the data model and error catalog, hashes and identifiers, the RQP codecs (Structured Fields, request and response fields, strict JSON, manifest, envelope, page revision, binding) and the test kit; 269 tests. Sprint S2 is next.
